# 🧠 Natural Language Processing (NLP)

A collection of Natural Language Processing techniques and projects implemented using Python. This repository covers the fundamentals of text processing, feature extraction, machine learning, and NLP-based applications.

## 📌 About

Natural Language Processing (NLP) is a field of Artificial Intelligence that enables computers to understand, process, and generate human language.

This repository explores different NLP concepts, including:

- Text preprocessing
- Tokenization
- Stopword removal
- Stemming and Lemmatization
- Part-of-Speech (POS) tagging
- Named Entity Recognition (NER)
- Bag of Words
- TF-IDF
- Word Embeddings
- Sentiment Analysis
- Text Classification
- Machine Learning for NLP

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- NLTK
- spaCy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook
